# Sources — Viral Election-Fraud Videos: What Did They Really Show?

_Every claim that carries a number or a name traces to a source here, grouped by the case file that checked it (the fact-check log has one numbered entry per claim). [primary] = the original court filing, order, sworn statement, official report, statute, data or paper; [secondary] = reporting or fact-checking about it. Where a page refused a direct fetch it was read through an archived copy, and that is said beside it. Where a court record or press release has no stable public address, it is cited by court, case number and date. Names of private people are never given; a few web addresses below carry a public figure's or a case's name in their slug because no other address exists._
