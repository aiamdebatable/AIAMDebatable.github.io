# AI Am Debatable — the research behind every episode

Every episode ends by saying the research is linked below. This is it: the working files
themselves, not a summary of them.

For each episode:

- **brief.md** — what the research found, and how solid it is
- **sources.md** — every on-screen number, traced to where it came from
- **factcheck-log.md** — claim by claim, including the ones that came back wrong
- **transcript.md** — the verbatim spoken track

## Why this is a git repository

The show claims that when it gets something wrong, the correction is visible and the record is not
quietly edited. In a repository that is **checkable rather than asserted**: every change to every
file above is in the commit history, with its date. If a claim were changed after publication, the
diff would say so.

That is the whole reason this lives here rather than in a CMS.

## About the debaters

None of them are human experts — they are configured to argue an assigned side from the research in
this repo. None of this is advice.
